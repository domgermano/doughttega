# Doughttega

Website for Doughttega — The Biscuit Deli. Artisanal ready-to-bake biscuit dough, small batch, made in Melbourne.

## Stack

- Vite + React + TypeScript + styled-components
- Deployed to GitHub Pages via GitHub Actions

## Dev

```bash
npm install
npm run dev
```

## Build & preview

```bash
npm run build
npm run preview
```

## Deploy

Pushes to `main` deploy automatically via GitHub Actions.

## Editing content

Market dates and other copy live in `src/data/` — edit those files to update the page without touching any components.
